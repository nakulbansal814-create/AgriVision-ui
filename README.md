# AgriVision-ui
AgriVision is an AI/ML and IoT-based smart farming solution designed to help farmers protect crops, prevent animal intrusion, reduce water wastage, and improve agricultural productivity. The system uses a machine-learning camera to detect animals and activate suitable animal-specific sound deterrents, while sending call or SMS alerts to farmers when intrusion persists. It integrates ESP32/ESP8266 microcontrollers, soil-moisture and temperature sensors, and servo-controlled water routing mechanisms to support intelligent irrigation and real-time field monitoring. A web-based dashboard provides sensor readings, weather forecasts, graphs, and alerts, enabling farmers to monitor field conditions and make informed decisions. By combining artificial intelligence, automation, and smart monitoring, AgriVision aims to make agriculture more efficient, sustainable, and technology-driven.
